# 🛒 Amazon Homepage Clone

A static, front-end web development project that replicates the user interface and structural design of the Amazon homepage. Built entirely with fundamental web technologies to practice pixel-perfect layouts and responsive design.


## ✨ Features
* **Detailed Navigation Bar:** Includes the Amazon logo, location selector, search bar, language switcher, sign-in button, and shopping cart icon.
* **Hero Section:** Features a promotional banner background image with gradient overlays.
* **Product Grid Layout:** Displays multi-category product cards featuring pricing, deal badges, and hover animations.
* **Responsive Layout:** Optimized using modern layouts for a seamless view across desktop, tablet, and mobile screens.
* **Comprehensive Footer:** Includes the "Back to Top" navigation anchor and multi-column site resource links.

---

## 🛠️ Technologies Used
* **HTML5:** Semantic markup structure (header, main, nav, section, footer).
* **CSS3:** Custom layout styling, Flexbox, CSS Grid, media queries, and hover transitions.
* **FontAwesome / Google Fonts:** Scalable vector icons and clean typography layout.
